
## How a Text File Works in Memory

When you open a file, Python doesn't load everything at once. It opens a **stream** — like a pipe connecting your program to the file. You then pull data through that pipe line by line or all at once.

Think of it like a book. Opening the file is like opening the book. Reading is like your eyes scanning the page. Closing is like shutting the book when you're done.

---

## Method 1 — `read()` — Reads EVERYTHING at once

```python
file = open('numbers.txt', 'r')
content = file.read()
file.close()

print(content)
print(type(content))
```

If your `numbers.txt` is:
```
12
45
67
23
```

`content` becomes ONE giant string:
```
"12\n45\n67\n23\n"
```

`\n` means newline — the invisible character that creates a new line. So `read()` gives you everything as one string including all those newlines.

This is why `int(file.read())` crashes — you're trying to convert `"12\n45\n67\n23"` into a number, which is impossible.

---

## Method 2 — `readlines()` — Reads into a List automatically

```python
file = open('numbers.txt', 'r')
lines = file.readlines()
file.close()

print(lines)
print(type(lines))
```

Output:
```python
['12\n', '45\n', '67\n', '23\n']
```

Now it's a list! But notice each item still has `\n` attached. So you need to clean each one:

```python
file = open('numbers.txt', 'r')
lines = file.readlines()
file.close()

numbers = []
for line in lines:
    clean = line.strip()    # removes \n and spaces
    numbers.append(int(clean))

print(numbers)   # [12, 45, 67, 23]
```

`strip()` is the key — it removes whitespace AND newline characters from both sides of the string.

---

## Method 3 — `readline()` — Reads ONE line at a time

```python
file = open('numbers.txt', 'r')

line1 = file.readline()   # reads "12\n"
line2 = file.readline()   # reads "45\n"
line3 = file.readline()   # reads "67\n"

file.close()

print(line1.strip())   # "12"
print(line2.strip())   # "45"
print(line3.strip())   # "67"
```

This is useful when you only need specific lines, not the whole file.

---

## Method 4 — Loop directly (most common in real code)

```python
file = open('numbers.txt', 'r')

numbers = []
for line in file:           # Python loops through each line automatically
    clean = line.strip()    # remove \n
    if clean:               # skip empty lines
        numbers.append(int(clean))

file.close()
print(numbers)   # [12, 45, 67, 23]
```

When you loop `for line in file`, Python automatically gives you one line per iteration INCLUDING the `\n`. That's why `strip()` is always needed.

---

## Method 5 — `with` statement (professional standard)

```python
with open('numbers.txt', 'r') as file:
    numbers = []
    for line in file:
        clean = line.strip()
        if clean:
            numbers.append(int(clean))

print(numbers)   # [12, 45, 67, 23]
```

The `with` block automatically closes the file when the block ends — even if your code crashes halfway through. This is the standard way professionals write file reading code. Always use `with` in real projects.

---

## What `strip()` Actually Does

This is important to understand deeply:

```python
line = "   12\n  "

print(line.strip())    # "12"     removes BOTH sides
print(line.lstrip())   # "12\n  " removes LEFT side only
print(line.rstrip())   # "   12"  removes RIGHT side only
```

For file reading you almost always want `strip()` — both sides cleaned.

---

## The Full Picture — What Happens Step by Step

Say your `numbers.txt` contains:
```
12
45
67
```

Here's exactly what happens in memory:

```
open file
    ↓
file stream created → points to start of file
    ↓
loop iteration 1 → pulls "12\n" from stream → strip() → "12" → int() → 12 → append to list
    ↓
loop iteration 2 → pulls "45\n" from stream → strip() → "45" → int() → 45 → append to list
    ↓
loop iteration 3 → pulls "67\n" from stream → strip() → "67" → int() → 67 → append to list
    ↓
loop ends → file closed
    ↓
numbers = [12, 45, 67]
```

---

## Open Modes — The Second Argument

```python
open('file.txt', 'r')    # read only (default)
open('file.txt', 'w')    # write — ERASES existing content!
open('file.txt', 'a')    # append — adds to end of file
open('file.txt', 'r+')   # read AND write
```

Always use `'r'` when you just want to read. Never use `'w'` unless you want to overwrite.

---

## Writing TO a File (bonus)

Since you're learning file handling deeply — here's how writing works too:

```python
numbers = [12, 45, 67, 23, 89]

with open('numbers.txt', 'w') as file:
    for num in numbers:
        file.write(str(num) + '\n')   # write each number on its own line
```

This is how you'd CREATE your `numbers.txt` file from Python itself instead of making it manually.

---

## The Complete Pattern You'll Use Forever

```python
# READING from a file
with open('filename.txt', 'r') as file:
    data = []
    for line in file:
        clean = line.strip()
        if clean:                    # always skip empty lines
            data.append(clean)       # or int(clean) or float(clean)

# WRITING to a file
with open('filename.txt', 'w') as file:
    for item in data:
        file.write(str(item) + '\n')
```

Memorize this pattern. You will use it in almost every project you ever build — web apps, data science, game development, automation scripts, all of it reads and writes files constantly. 💡
